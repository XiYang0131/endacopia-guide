Endacopia Walkthrough

Updated July 31, 2026 Chapter route Spoilers

Quick Answer

For a clean Endacopia completion route, play through the opening and Chapter I normally, save before the Saw Box code 471, branch Toy Saw for Ending A, reload for the real Saw Ending B, then use a Chapter I backup to complete the three hidden secrets for Ending C.

Opening Route

  1. Click the poster if you see it. Steam lists Achievement Unlocked as the poster interaction achievement.
  2. Try the soccer mini-game before moving on. Footwork Master requires a soccer score of 100 points.
  3. Track optional interactions early. Water Break, dice, fishing, and hidden-route cleanup are easier when you keep notes instead of relying on memory later.

Chapter I Route

Chapter I is the most important chapter for secret-route preparation. Do a normal route first, but keep notes and a backup before resolving the major area bosses.

Area Main Progress Secret / Achievement Watch
Office / Core Acquire George's Cog and defeat the Core for System Override. Office secret uses the Telescope, Jobs app phone call, vending-machine wait, and symbol sequence.
Misery Town Progress toward Snake Oil and the area boss route. Bring the Metal Detector to the cinema and follow the remote/map/checkerboard route.
Timesville Complete the investigation route and area progress. Use the Metal Detector, catch 18 unique fish, then use the monochrome shack key.

Chapter II Route

Chapter II contains a boss loop and several mechanically different encounters. Treat each encounter as a standalone puzzle: identify the pattern, survive the gimmick, and keep a save before the battle-versus-avoidance decision.

  1. Prepare for repeated boss formats. Source walkthroughs describe distinct mini-games and pattern checks across this chapter.
  2. Do not overwrite branch saves if you are achievement hunting. Some achievements require fighting a boss, while others require avoiding that same boss.
  3. Keep one clean route save. You will need stable progress for the saw branch later.

Chapter III Route

  1. Reach the Chameleon route. Fighting unlocks No Strings Attached, while avoiding the battle unlocks Case Closed.
  2. Reload your branch save if needed. Do one Chameleon outcome, reload, then complete the other if you are chasing 100% achievements.
  3. Use Henry's computer. Open the password file and use Saw Box code 471.
  4. Branch the saw choice. Toy Saw leads toward Escape / Ending A. Working Saw leads toward Return / Ending B.
  5. For Ending C, ignore the late door. After all three Chapter I secrets are done, return to Mellow's room instead of opening the door that asks to be opened.

FAQ

What is the Saw Box code?

The Saw Box code is 471.

Should I choose the Toy Saw or the real Saw?

Choose both on separate saves. Toy Saw is used for Ending A / Escape. The working Saw is used for Ending B / Return.

When should I attempt Ending C?

After you have Escape and Return. Then restore a late Chapter I save and complete the Misery Town, Timesville, and Office secrets.
