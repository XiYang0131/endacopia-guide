How to Use Character Pages

Use character pages as route context, not as a replacement for the walkthrough. If a character is tied to an ending branch, achievement, item handoff, or puzzle clue, the character page links back to the exact guide that explains the step.

  • For ending routes. Start with the all endings guide, then use character pages to understand names and late-route references.
  • For puzzle progress. Use the walkthrough first, then check character notes when dialogue points you toward another area.
  • For achievements. Use the achievement checklist when a character action looks optional or missable.
