Endacopia 100% Achievement Checklist

Updated July 31, 2026 16 achievements Saves progress locally

Quick Answer

Endacopia has 16 Steam achievements. For a low-replay 100% route, keep boss-branch saves, keep a Saw Box save for Escape and Return, restore a near-complete Chapter I save for Stay, and treat The Yeti plus optional mini-games as final cleanup.

Recommended 100% Route

  1. Run 1: normal route plus battle outcomes. Click the poster, track water interactions, play side games when available, and keep saves before AI, Trapezist, and Chameleon battle choices.
  2. Run 2: branch cleanup from saves. Reload boss saves for avoidance achievements, then use the Saw Box save to split Escape and Return.
  3. Run 3: Stay preparation. Restore a near-complete Chapter I save, complete Misery Town, Timesville, and Office secrets, then return to Mellow's room at the final door.
  4. Run 4 or cleanup: hidden and optional tasks. Finish The Yeti / Find Andy, every fish, dice wins, soccer 100, water, and 15 enemy defeats.

FAQ

Does this checklist sync with Steam?

No. It saves only in your browser on this device. Use it as a planning tool while Steam remains the source of truth.

Can I reset the checklist?

Yes. Use the Reset button at the top of the checklist to clear local progress.

Which achievements need separate saves?

The boss battle / avoidance pairs and the Escape / Return saw branch are the highest-priority save splits.
