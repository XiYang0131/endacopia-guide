Guide Index FAQ

Which page should I use first?

Use the Beginner Guide or Prologue Walkthrough for a new save. Use the Puzzle Solutions hub when you already know the exact blocker.

Are the endings and achievement pages connected?

Yes. Ending pages link to the relevant achievement and secret checklists, while the 100% page links back to branch-specific route guides.

Are these official Endacopia pages?

No. Endacopia Guide Hub is an unofficial fan-made reference. Each page labels its source status and remaining proof targets so route notes can be corrected as new evidence arrives.
