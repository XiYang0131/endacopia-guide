Quick Answer

The Endacopia full game is the version to use for all guides on this site. It includes the achievement routes, the Saw Box 471 branch, Ending A, Ending B, and secret Ending C.

Full Game Completion Plan

  1. Play one normal route first. Learn the puzzle language before chasing every hidden route.
  2. Save before Saw Box 471. This save controls the Toy Saw / real Saw branch for Ending A and B.
  3. Do the Chameleon death once. Fatal Performance requires losing to the Chameleon before winning.
  4. Replay Chapter I secrets for Ending C. Complete Misery Town, Timesville, and Office secrets before finishing the final route.
  5. Clean up optional achievements. Catch fish, show Roger's bird to Mellow, find easter eggs, and check Adaminia after the main routes.
