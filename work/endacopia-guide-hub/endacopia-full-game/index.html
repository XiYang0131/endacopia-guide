Quick Answer

The Endacopia full game is the version to use for all completion guides on this site. Older demo/prologue guides help with the opening house route, but the Steam full game adds Chapter I hubs, achievement routes, the Saw Box 471 branch, Ending A, Ending B, secret Ending C, and The Yeti hidden route.

Full Game Completion Plan

  1. Play one normal route first. Learn the puzzle language before chasing every hidden route.
  2. Save before Saw Box 471. This save controls the Toy Saw / real Saw branch for Ending A and B.
  3. Keep boss-branch saves. AI, Trapezist, and Chameleon each have battle/avoidance achievements, so save before committing to one resolution.
  4. Replay Chapter I secrets for Ending C. Complete Misery Town, Timesville, and Office secrets before finishing the final route.
  5. Clean up optional achievements. Finish every fish, beat every gambler at dice, reach 100 soccer points, hydrate three times, and complete the Andy / The Yeti route.
