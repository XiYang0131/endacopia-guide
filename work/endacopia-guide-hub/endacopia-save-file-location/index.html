Endacopia Save File Location - Backup and Restore Guide

Updated September 20, 2026 Windows SteamOS
Verification Documented paths; recovery not playtested
Last checked September 20, 2026
Evidence Steam Cloud announcement, cloud configuration and original community guide

Quick Answer

On Windows, check %USERPROFILE%\Saved Games\Endacopia\ for files matching agssave.*. On SteamOS/Proton, use the game's Steam library and the steamapps/compatdata/2684630/pfx/ prefix shown below. Close the game and copy the whole save folder to a separate backup before changing anything. Steam Cloud was enabled in patch 1.04; it does not establish that an overwritten save can be recovered.

Save Locations

Windows: C:\Users\<your name>\Saved Games\Endacopia\

SteamOS / Proton: <SteamLibrary>/steamapps/compatdata/2684630/pfx/drive_c/users/steamuser/Saved Games/Endacopia/. The original community guide uses ~/.local/share/Steam/ as its example library; an alternate library or SD-card installation may have a different prefix.

What supports these paths? SteamDB's copy of the app's cloud configuration lists WinSavedGames, folder Endacopia and pattern agssave.*. An original Steam community backup guide independently documents the Windows and default SteamOS paths. SteamDB is not Valve, and this site has not performed a local restore test.

Safe Backup Steps

  1. Close Endacopia. Do not copy files while the game is writing saves.
  2. Copy the whole folder. Put the backup somewhere outside the active save directory. Copy, do not move or delete, the live files.
  3. Name the backup clearly. Include route state, such as chapter-1-before-office-secret.
  4. Check the backup before relying on it. Confirm that it contains save files, and record their size and modification time. An empty folder is not a backup.

Steam Cloud, Overwritten Saves and Restore Limits

The official 1.04 announcement confirms cross-device Steam Cloud support. That is a sync feature, not evidence of a recoverable history of every route or save. Do not delete a local folder to try to force recovery.

If you have a known-good backup, the original community guide describes restoring its complete contents while the game is closed. First preserve a separate copy of the current folder too: replacement can discard newer progress. If Steam presents a sync conflict and you cannot identify the intended version, stop before choosing an overwrite. Consult Steam Cloud support.

No backup, corrupt file or unexpected rollback? No universal repair is verified here. Keep the affected files, game version and error message. The 1.05 announcement offered developer help for the specific old crash when entering the dice room; it is not a promise to recover any overwritten save. Do not import an unknown player's save or edit save contents as a general fix.
