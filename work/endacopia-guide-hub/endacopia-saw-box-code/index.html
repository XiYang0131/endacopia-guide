Endacopia Saw Box Code

Fast answerCode 471Updated July 30, 2026

Quick Answer

The Saw Box code in Endacopia is 471. Save before opening the box, because the saw you choose affects Ending A and Ending B.

Where to Find the Code

  1. Reach Henry's computer route. Continue until you can use Henry's floppy disk.
  2. Open PASSWORDS.TXT. The password file gives the Saw Box code.
  3. Enter 471. Open Henry's Saw Box.
  4. Save before choosing. This is the important branching moment.

Which Saw Should You Pick?

Save Warning

If you want both Ending A and Ending B without replaying too much, copy or keep a save before selecting the saw. Then complete one route, reload, and choose the other saw.

FAQ

Does the Saw Box code change?

Current source-backed routes list the code as 471.

Does the saw choice unlock Ending C?

Current sources say Ending C depends on completing Ending A, Ending B, and the three Chapter I secrets. The saw choice itself is the A/B branch.
