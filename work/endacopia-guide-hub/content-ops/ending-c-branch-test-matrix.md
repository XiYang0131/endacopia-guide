## Capture protocol

1. Record the exact game version and platform before starting.
2. Start from a copied near-complete save and record the branch state.
3. Capture one proof image at each condition and the final achievement unlock.
4. Record whether the result matches the public route, partially matches, or
   contradicts it.
5. Update the affected guide and the keyword-page-evidence ledger together.
